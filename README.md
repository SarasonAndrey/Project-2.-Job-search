# Проект 2 "Поиск вакансий"

## Описание:

Проект для поиска и работы с вакансиями. В проекте реализованы классы и функциональность 
для получения данных по вакансиям с сайта HeadHunter, 
работа с экземплярами вакансий, сохранение, добавление, удаление вакансий из файла.

##Установка и настройка проекта

1. Клонируйте репозиторий:
```
git clone https://github.com/SarasonAndrey/Project-2.-Job-search.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

# Использование:
1. Перейдите в директорию проекта:

   cd ваш_проект  

2. Установите зависимости проекта:
```
    poetry install (или как указано выше)
``` 

3. Для работы с API HeadHunter создайте экземпляр класса:

    hh_api = HeadHunterApi()
   

4. Для работы с JSON файлами используйте класс JsonSaver:

   json_saver = JsonSaver()
   

5. Создайте экземпляр класса Vacancy для работы с вакансиями:
```
new_vacancy = Vacancy("Python", "12", 100, 150, "Требования: опыт работы от 3 лет")
```
